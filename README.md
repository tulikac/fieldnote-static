# Fieldnote Static

A realistic local-events application built with plain HTML, CSS, and JavaScript. It has no package manager, build command, framework, or backend.

## Run

Open `index.html` directly in a browser. You can also serve the folder from any static file server.

## Test surfaces

- Static HTML entry point and linked CSS/JavaScript
- Responsive layout
- Remote images and web fonts
- Search and category filtering
- Native dialog interaction
- Theme, saved events, and RSVP state in `localStorage`
- Accessible controls and reduced-motion support
